#problem statement
delivery in the rural and urban areas face a lot a challenges as in delays, traffic, inefficient roading networks. delivery agents must transfer packages to the specified destination using the specified routes. 
the goal is to design a system that makes effective routes while also reducing travel time and cost.

#scope of the project
represent the city as a grid with roads, obstacles and delivery destinations
using DFS, BFS algorithms to determine the best path
sometimes displaying the shortest path for delivery

#target users
students studying AI, and algorithms
developers exploring pathfinding simulations

#high-level features
grid base city representations
vizualization of the chosen route
path length
number of steps required
effective time cost
